# AI Handover Guide - Compatibility Pointer

Dokumen status kanonik berada di [AI_HANDOVER_GUIDE.md](../AI_HANDOVER_GUIDE.md).

File ini dipertahankan agar tautan lama tidak rusak. Matrix status tidak diduplikasi di folder `docs/` karena salinan ganda sebelumnya menghasilkan klaim yang berbeda, path komponen yang salah, dan status `100% production-ready` tanpa bukti validasi.

Gunakan urutan berikut:

1. [AGENTS.md](../AGENTS.md) untuk aturan wajib dan batas regresi.
2. [AI_HANDOVER_GUIDE.md](../AI_HANDOVER_GUIDE.md) untuk status modul terbaru.
3. [STRUCTURE.md](STRUCTURE.md) untuk detail arsitektur dan riwayat.
4. [MENU_IMPLEMENTATION_COMMAND.md](MENU_IMPLEMENTATION_COMMAND.md) untuk workflow implementasi menu.
5. [BACKEND_READY_VERTICAL_SLICE.md](BACKEND_READY_VERTICAL_SLICE.md) untuk struktur layer wajib setiap menu.
6. [Obsidian Vault](obsidian-vault/00-HOME.md) untuk flow aplikasi, business logic, Netlify, revisi klien, dan decision log.

Jangan menambahkan matrix status baru di file ini. Perbarui dokumen kanonik dan changelog vault agar tidak terjadi mismatch.
